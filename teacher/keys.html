Scoring

Each knowledge item is one point. Days 1–4 have three items each; Day 5 has ten. Record first-check and latest-check scores separately. Improvement after feedback is expected. Do not average them or treat the latest score as independent test evidence.

For each day's four performance criteria, score 0 = missing or incorrect; 1 = partly supported, unclear, or missing one required component; 2 = complete, accurate, and supported by the student's actual observations or supplied facts. Total 8 points per day, reported separately from knowledge points. Suggested readiness signal: at least 6/8 with no 0 on a core standard component; use judgment and allow revision. This is a local teaching rule, not an Ohio cut score. Days 1 and 2 supply evidence for their single standard; Day 3 for troubleshooting; Days 4 and 5 integrate all three. Verify device observations in class where possible.

Model performance response

My task was short text editing. My criteria were that words appeared, the edit appeared, and Check trial responded. I kept the sentence and page the same. All three trials showed Our club meets Friday. and feedback. This device can handle this short text task because I observed all three criteria. I did not test video editing. Accept different truthful results; a blocked test earns credit if the student identifies the limitation and avoids an unsupported conclusion.

Four criteria · 0–2 points each

  1. Names the task and all three observable criteria.
  2. Describes a consistent process and three actual trial observations, including failures or blocks.
  3. Makes a conclusion justified by the observations.
  4. States an untested capability or another clear limitation.

Model performance response

Both A + Text Pad and B + Text Pad meet the text task because each device has a keyboard and readable screen and Text Pad edits text. A + Text Pad is the better choice for the stated battery goal because A uses less battery for text work. A + Voice Pad is unsuitable because Voice Pad does not edit typed announcements. Do not accept an unsupported claim about real device battery life.

Four criteria · 0–2 points each

  1. Identifies keyboard, screen, and text-editing software as requirements.
  2. Evaluates both named combinations accurately.
  3. Justifies A + Text Pad using the supplied battery criterion.
  4. Rejects A + Voice Pad using the missing text-editing capability.

The sentence did not appear after Send sample. I tested pretend Wi-Fi and it was connected; I checked pause status and it was paused. Four criteria · 0–2 points each

  1. Separates the symptom from possible causes.
  2. Reports two checks and their observed results.
  3. Chooses the evidence-supported safe solution and compares it with deletion.
  4. Reports a repeat of the original task and communicates a clear result.

Model performance response

Use the worked example as the model, but require the student's own developed test plan and truthful three-trial evidence. Paragraph 1 must not treat fictional battery facts as a real measurement. Paragraph 2 must explain that both text combinations work and A wins the stated battery goal. Paragraph 3 must report Wi-Fi connected, pause on, resume, and successful Send sample after the change. Return missing parts for revision.

Four criteria · 0–2 points each

  1. Personal evaluation: student-developed process with chosen edit, criteria, numbered steps, constants and repeat rationale; three real observations, supported conclusion, and limitation.
  2. Combination evaluation: both pairs checked against hardware and software needs; choice justified by battery fact.
  3. Troubleshooting: two causes tested, evidence-supported safe solution, and repeated-task verification.
  4. Communication: clear enough to follow; distinguishes real observations from fictional facts.

Model performance response

A: Accept an honest repeatable typing evaluation with all three actual observations and a bounded conclusion. B: Both combinations support text; A + Text Pad fits the supplied lower-battery criterion. Score the written work separately from the 10-point knowledge test.

Four criteria · 0–2 points each

  1. A: Student-developed task/process, criteria, fair repeated steps, three observations, evidence-based conclusion, and limit.
  2. B: Both combinations evaluated with hardware/software requirements and justified battery choice.
  3. C: Symptom, two evidence checks, safe chosen solution, and repeated-task result.
  4. Communication: readable reasoning; actual observations; no unsupported general claims.

Lab keys and diagnostic feedback

Typing: exact final text, ignoring only leading/trailing spaces, is Our club meets Friday. Three successful checks do not certify every device capability. Failed/blocked trials can support a careful evaluation. Award evidence and reasoning, not an all-success result.

Combinations: text task: A + Text Pad and B + Text Pad meet requirements; A is preferred for the fictional lower-battery goal. Either device + Voice Pad fails typed-text editing. Audio task: only B + Voice Pad meets both microphone and recording requirements. A + Text Pad misses both; A + Voice Pad misses microphone; B + Text Pad misses recording software.

Troubleshooting: send while paused → no text; Wi-Fi → connected; pause → paused; resume → running; send → sentence appears. Check-order differences are acceptable. Require evidence before a cause claim and verification after the fix. “Consider deleting files” must explain why deletion is not justified, without deleting any data. “Reload case” returns the simulation to paused while keeping the history and student notes.
